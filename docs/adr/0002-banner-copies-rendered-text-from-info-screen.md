# The banner copies already-rendered text from the info screen

The banner does not call the game's text renderer. Each frame it reads the tiles the game has already drawn on the info screen's text layer and copies them, recoloured, into an unused tile layer of the gameplay screen; turn-order heads are copied the same way from the info screen's sprites. We chose this over driving the game's own text and menu code because it works without understanding that code and automatically follows language, law and objective changes. The cost is that the banner can only show what the info screen currently shows, is tied to that screen's layout (a signature check on its frame decides whether a battle HUD is present), and is limited to DS-resolution 2D, which becomes a problem under widescreen.
